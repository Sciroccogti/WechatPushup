# 随身健身教练

微信原生小程序，WXML/WXSS/JavaScript/JSON，无第三方框架、登录或后端。当前为**0.6.2统一现代视觉（阶段6视觉修订）**，支持历史详情、日期筛选、周月统计、文本备份导入/导出；保留能力评估、长期计划、传感器与触屏训练。延续蓝色主题，统一圆角/留白/卡片/按钮/文字层级；首页主卡与简洁项目卡、设置分段标签和记录统计采用一致的视觉尺度。详见[设计修订](docs/modern-design.md)。

已针对“开始按钮无响应、平板需再点一次”的反馈修复事件隔离和刷新逻辑：按钮使用完整触摸/点击链，待机和暂停不轮询刷新，运行时只更新变化字段；涟漪改用小图层扩散。四项目一次点击启动的模拟回归通过，真机响应需复核。

训练中暂停/结束至少160rpx，其他训练操作至少136rpx；休息页同步放大。准备界面改为一屏纵向布局：目标、方式选择、调参入口与整行开始按钮；本组操作放入弹层。开始/继续默认176rpx，短屏160rpx；训练中的大触区保持。详见[本次修改与验证](docs/exercise-settings-layout.md)和[原按钮尺寸调整](docs/large-training-buttons.md)。

## 现在的流程

底部训练页直接选项目 → 查看长期计划 → 首次能力评估（实际测试或手动填写）→ 选择计数方式 → 五组训练 → 自动组间休息 → 总结与疲劳反馈 → 保存并更新下次计划。

- 项目卡片不再显示1–4编号，独立选择页已删除；底部训练页和执行训练页都支持排序，执行页暂停后可直接更换项目。
- 俯卧撑：光学实验模式可与触屏同时计数，保留手动纠错；仅该运动可以开启摄像头。
- 仰卧起坐：加速度确定离开/返回起始姿态的完整周期，旋转信号辅助确认、不会独立计数。手机固定胸前/上身，起始姿态静止校准。辅助旋转不可用时明确提示仅用加速度；主加速度不可用则降级触屏。仍是待真机验证的实验检测。
- 深蹲保留胸前陀螺仪计数，默认X轴，可切自动选轴；上身转动较小可能漏计。三个计次项目都支持触屏并行补数和手动纠错。
- 四个项目开始后提供大面积触摸区域（主要区域至少60vh）：有效触碰在落点扩散涟漪并切换浅蓝色系背景，显示+1或计时中；控制按钮不误加数。
- 平板支撑：轻触大区域或按钮开始/继续计时；计时中触屏只播放反馈，不暂停或重置。无需传感器，计划训练支持五组计时。
- 传感器与触屏共用去重窗口；传感器周期中已触屏计数时，该周期完成事件不再加一。主要传感器仍保持单一。
- 达到目标自动进入休息；休息倒计时结束提示就绪，主动开始下一组。可提前结束/延长休息、暂停、跳过、调整目标和手动纠错。
- 默认按累计训练时长排序，保留最近使用选项。只在底部训练页、执行页提供切换，运动设置页没有排序；只累计实际训练，休息、暂停、校准、后台及浏览不计入。
- 设置页内部提供四个运动标签。俯卧撑保留光学调参；仰卧起坐可调离开/返回阈值、稳定时间、周期长短、冷却、加速度平滑/冲击过滤、辅助旋转轴与阈值；深蹲保留独立陀螺仪参数。均可实时测试、拖动即时应用、松手保存，修改会清半周期；切标签释放旧硬件，进入标签不自动采集。平板只说明计时行为。
- 底栏“记录”按日期查看已保存训练，可按运动和起止日期筛选，每次加载20条；点击查看每组目标/实际/用时/休息、训练方式、疲劳和完成率。总结保存后可直接进入此条详情。
- 记录页进入“数据统计”，分运动查看本周/本月/全部总量与训练次数、实际时间、训练天数、连续天数、最好成绩、五组完成率、最近14天训练量图和最近12次能力评估。次数和秒数始终分开。
- 记录页底部可导出JSON文本备份，长按全选复制并另存；导入粘贴后先预览再确认合并。重复ID跳过、同ID冲突及已有计划保留本机、不重复推进计划；确认删除后留墓碑防旧备份复活。删除不回滚已调整计划或累计时长排序。

## 快速运行

微信开发者工具打开 **`D:\Codes\WechatPushup`**，确认小程序根为 `miniprogram/`，使用已有AppID与稳定基础库（建议≥2.32.3）。无需云开发、npm构建或服务器。

1. 选择运动进入计划页；首次点击能力评估，可填写当前已知最大能力，或进入一次实际测试后结束并确认结果。
2. 计划页显示五组目标、休息与调整原因。恢复期显示下次训练时间；不要求每天高强度训练。能力测试后也安排恢复。
3. 进入五组训练，先用触屏/手动检查完整流程；平板支撑按秒计时。训练/休息页之间替换导航，避免堆积页面栈。
4. 总结页选择疲劳并保存；离开总结时按当前选择自动保存，未选择时按“适中”处理。同一结果不会重复推进计划。
5. 真机预览用微信扫码。相机需要在小程序后台如实配置隐私用途，用户主动同意后才能采集；陀螺仪不申请虚构的相机/传感器scope。后台、暂停、休息或离开都会停采集。

训练数据按20条分块保存，先写新块后提交索引；旧版数据首次修改前保留迁移副本，失败保留原记录。不会按数量自动清理训练历史。备份只含记录/能力/计划，传感器参数和使用时长排序偏好保持本机；容量不足时提示重试/导出。当前进行中的会话仍只在内存，后台暂停可继续，进程被系统清除后不能恢复未结束会话；累计时长约每5秒保存检查点，退出补齐。所有功能离线，云备份仅保留设计契约。

## PowerShell 检查

需要Node.js≥20，没有包依赖，无需npm install：

```powershell
Set-Location D:\Codes\WechatPushup
npm.cmd test
npm.cmd run check
npm.cmd run check:wechat
npm.cmd run simulate -- 180
```

`npm.cmd`避免PowerShell脚本执行策略限制。simulate输出半年策略演进示例，假设能力20次、每3天训练且稳定完成，**不是人体训练效果预测**。

已通过119项测试、静态检查和微信内置编译器检查（正式15份WXML/17份WXSS，Demo1份WXML/2份WXSS）。记录专项覆盖筛选/统计、迁移备份、分块/索引失败、进程中断恢复、重复导入/冲突/删除墓碑、重启和实际训练保存往返；原102项回归保持。记录/统计/详情在320与390宽度下的6种浏览器近似截图无页面横向溢出。这不等于微信原生页面或Android/iPhone实测通过。详见[阶段6记录说明](docs/phase-6.md)。

## 目录入口

```text
miniprogram/config/training-policy.js  配置化训练/恢复/减量/复测参数
miniprogram/domain/training/           独立计划/进展算法与会话状态机
miniprogram/domain/gyro/fsm.js         角速度完整往返检测
miniprogram/domain/situp/fsm.js        加速度主导、旋转辅助的仰卧起坐周期
miniprogram/domain/optical/            亮度与明暗状态机
miniprogram/domain/records/            记录校验、日期、查询统计、备份合并
miniprogram/services/gyro-source.js    陀螺仪公开API生命周期
miniprogram/services/situp-source.js   加速度/辅助旋转生命周期与降级
miniprogram/services/training-page.js  训练/休息页面控制器
miniprogram/services/training-store.js 能力/进展与训练结果
miniprogram/services/preferences.js    光学/深蹲/仰卧起坐融合参数、累计时长、排序与最近使用
miniprogram/services/storage/          版本化本地文档适配器
miniprogram/services/storage/record-document.js  记录分块、迁移和事务恢复
miniprogram/pages/                    评估、计划、方式、训练、休息、总结等
experiments/optical-demo/             原始阶段0独立光学实验
```

本地数据不包含图片、原始传感器帧、账号或云端内容。偏好兼容schema1/2/3→4；训练数据兼容schema1→分块schema2。旧能力历史只能补充原先保存的最近一次能力值，无法还原此前未记录的评估。未知/损坏版本保留不覆盖；AppID与工具设置的用户改动保留且不纳入提交。
