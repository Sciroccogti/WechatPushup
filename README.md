# 随身健身教练

微信原生小程序，WXML/WXSS/JavaScript/JSON，无框架、无需登录或后端。用户要求直接进入阶段 4，本次已接入**光学实验模式、设置内实时调参、必要的统一计数/触屏降级，以及最近使用排序**。光学实际手机效果仍待真机验证。

## 现在可以使用

- 首页和项目选择共用最近使用顺序，不按计次/计时分组。打开合法项目的训练页即记为最近使用；未使用项目保持原配置顺序，去重后只保留项目 ID。
- 俯卧撑、仰卧起坐、深蹲提供自由计数：触屏、光学实验模式、手动 +1、撤销、清零、暂停和继续。不同自动源互斥，次数保留在当前页面内存。
- 设置页可开启前置摄像头看实时亮度、基准、比值、明暗状态和测试次数；滑动阈值立即生效，松手保存。顶部实时读数条在滚动时保持可见。
- 训练页的“光学阈值与实时测试”进入同一套调参界面；原训练暂停，返回后保留次数，点击继续会重新校准。
- 个人计划、五组流程、训练记录、统计、备份与平板支撑计时尚未实现。没有训练记录保存或网络请求。

## 快速体验

1. 微信开发者工具打开 **`D:\Codes\WechatPushup`**，根 `project.config.json` 指向 `miniprogram/`。使用已有 AppID，稳定基础库 **≥2.32.3**。不启用云开发、不构建 npm。
2. 工具中可检查项目排序、触屏计数。进入“设置”，点击“播放模拟周期”，默认参数应新增 3 个测试周期；模拟不代表硬件通过。
3. 真机预览前，在小程序管理后台配置用户隐私保护指引，如实声明相机仅在设备内存中提取亮度，不保存或上传画面。点击工具“预览”，有开发权限的微信扫码。
4. 手机进入“设置”→“开启前置摄像头”，主动同意隐私/相机授权。固定手机，前置镜头无遮挡约 3 秒，等 READY。
5. 用手掌遮挡镜头后移开，观察比值和测试次数；滚动调节遮挡/恢复阈值、最短持续、冷却、平滑。拖动保持相机与基准，清除未完成半周期；松手保存到本机。
6. 训练页点击“开启光学”会在授权和校准后进入自由计数。权限/无帧/异常光线失败时提示并降级触屏。进入后台、暂停、离开页面会停采集；继续光学必须重新校准。

光学来自**前置摄像头图像亮度**，不是内置环境光传感器或 lux，不判断动作是否标准。脸靠近可能不变暗，自动曝光也可能影响效果；手掌遮挡通过不能证明实际动作通过。请分别在 Android/iPhone 记录结果。

## PowerShell 检查

需要 Node.js ≥20，无依赖，不必安装包。`npm.cmd` 避免 npm.ps1 的执行策略限制：

```powershell
Set-Location D:\Codes\WechatPushup
npm.cmd test
npm.cmd run check
npm.cmd run check:wechat
```

已通过 50 项测试、两套工程静态检查，正式工程 14 份 WXML/16 份 WXSS 及 Demo 的 1 份 WXML/2 份 WXSS 编译。测试中的 wx、相机帧和计时器是模拟对象；原生授权、界面渲染、真实取帧、精度、耗电与系统资源释放仍待真机确认。

## 本地数据与工程

`fitness.preferences.v1` 只保存版本号、六项光学参数和最近项目 ID，不包含图像、亮度历史或训练记录。未知/损坏版本不覆盖，读写失败显示临时生效提示。开发者工具的 AppID/本地选项改动保留，不随阶段提交。

```text
miniprogram/
  config/optical.js                参数默认值、范围与迟滞校验
  domain/counter/manager.js        统一计数与触屏防抖/长按/多点控制
  domain/optical/                  亮度抽样、明暗状态机与模拟信号
  services/preferences.js         版本化偏好与最近使用
  services/camera-capabilities.js  平台、基础库和公开相机能力检测
  services/optical-page.js         授权、取帧、生命周期、即时调参
  services/optical-settings-page.js 设置/校准共用页面工厂
  templates/optical.wxml           信号面板、实时调参、隐私同意模板
  pages/                          首页、选择、自由训练、设置/校准等12页
experiments/optical-demo/          保留原阶段0实验，独立导入
scripts/                          静态检查、微信编译、官方API核查
tests/                           算法、存储、页面与生命周期回归
docs/                            API证据、阶段交付与真机步骤
```

原阶段 0 Demo 仍可单独导入 `D:\Codes\WechatPushup\experiments\optical-demo`。正式域算法源自实验并增加即时配置，双方分别回归测试，正式工程不从实验目录跨根引用。
